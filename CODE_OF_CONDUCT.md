# Código de conduta

O Vintém adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, assuma boa-fé, critique ideias e não pessoas, e
lembre que todo mundo aqui é voluntário. Assédio, discriminação e ataques
pessoais não são tolerados em issues, PRs, Discussions ou qualquer canal do
projeto.

## Como reportar

Escreva para o mantenedor pelo GitHub
([@mateus-vitor-ferreira-dev](https://github.com/mateus-vitor-ferreira-dev)) pedindo um canal privado.
Todo reporte é tratado com sigilo.
