O Vintém não termina TLS. Ele fica atrás de um proxy, e este guia usa o Caddy, que
emite e renova o certificado sozinho.

Você vai precisar de um servidor com Docker, de um domínio apontando para ele, das
portas 80 e 443 abertas e das [credenciais do seu banco](/conceitos/contas-e-certificados/).

## 2. A chave mestra e o `.env`

```bash
docker run --rm ghcr.io/vintemhq/vintem:0.11.0 chave gerar
```

Crie o `.env`, na mesma pasta, com a chave gerada:

```bash title=".env"
VINTEM_VERSAO=0.11.0
VINTEM_DOMINIO=vintem.suaempresa.com
VINTEM_MASTER_KEY=a-chave-gerada
```

```bash
chmod 600 .env
```

:::danger[Guarde a chave mestra fora do servidor]
Ela cifra as credenciais dos bancos. Sem ela, um backup não recupera as credenciais, e
não há como gerá-la de novo. Veja [Segurança](/operar/seguranca/).
:::

## 3. Subir

```bash
docker compose up -d
curl https://vintem.suaempresa.com/health
```

```json
{"status":"ok","version":"0.11.0"}
```

## 4. Cadastrar a conta

O comando lê os segredos de arquivos. Monte uma pasta só para isso, com os arquivos
legíveis pelo usuário da imagem, e apague tudo depois:

```bash
mkdir segredos
cp ~/secret.txt ~/certificado.p12 segredos/
chmod 644 segredos/*

docker compose run --rm -v "$PWD/segredos:/segredos:ro" vintem conta criar \
  --id minha-loja --nome "Minha Loja" --psp efi \
  --chave sua-chave-pix@exemplo.com --ambiente producao \
  --client-id SEU_CLIENT_ID --client-secret-arquivo /segredos/secret.txt \
  --certificado /segredos/certificado.p12

rm -r segredos
```

As flags de cada banco estão em [Contas e certificados](/conceitos/contas-e-certificados/).
Os outros comandos, com o Vintém no ar, rodam com `docker compose exec`.

## 5. Ligar o webhook do banco

```bash
docker compose exec vintem /vintem conta webhook minha-loja \
  --url-publica https://vintem.suaempresa.com
```

O comando gera a URL de aviso e a registra no banco. Os guias de cada banco contam os
detalhes, como o mTLS do webhook no [Efí](/gerado/efi/).

## 6. Criar a API key da sua aplicação

Dê só o que a aplicação precisa e restrinja à conta:

```bash
docker compose exec vintem /vintem apikey criar --nome minha-app --conta minha-loja \
  --escopo cob:read --escopo cob:write
```

Guarde o token, que aparece uma vez só.

## 7. Receber os eventos

```bash
docker compose exec vintem /vintem destino criar --url https://sua-app.com/webhooks/vintem
```

Veja como [conferir a assinatura](/conceitos/webhooks-de-saida/).

## Acompanhar

- **Saúde:** aponte seu monitor para `GET /health`, que não exige API key.
- **Logs:** `docker compose logs -f vintem`.
- **Entregas que desistiram:** `docker compose exec vintem /vintem dlq listar`.

## Antes de ir para o ar

- [ ] Backup do volume agendado e [restauração testada](/operar/backup-e-atualizacao/)
- [ ] Chave mestra guardada fora do servidor
- [ ] `.env` com permissão `600`
- [ ] Uma cobrança de valor baixo criada, paga e devolvida na conta real
- [ ] Destino de eventos respondendo 2xx e conferindo a assinatura
